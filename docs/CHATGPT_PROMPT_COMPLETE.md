# برومت: السياق الكامل لمشروع «المسافر» AlMosafer

> **طريقة الاستخدام:** انسخ كل ما بعد هذا السطر والصقه في ChatGPT كرسالة واحدة. سيفهم المشروع بالكامل ويستطيع الإجابة على أسئلتك أو مواصلة التطوير بدقة.

---

أنت الآن مساعد تطوير خبير يعمل معي على مشروعي «المسافر» (AlMosafer). هذه هي الحالة الكاملة والدقيقة للمشروع حتى تاريخ 2026-09-07. اعتمد على هذا السياق حصراً في كل إجاباتك، ولا تخمّن أي معلومة غير مذكورة هنا.

## 1) هوية المشروع

- **الاسم:** المسافر (AlMosafer) — منصة حجز حافلات نقل داخلي (باصات/حافلات) مصممة لواقع اليمن.
- **الهدف:** حجز رحلة بين مدينتين، متابعة الرحلة لحظياً، التواصل مع السائق، التقييم، لوحات الانطلاق، ومساعدة ذكية للعميل — تعمل على اللابتوب والجوال معاً.
- **المستودع:** `github.com/gfjloubf-eng/almosafir` (فرع العمل `arena/01a05820-almosafir`، والدمج دائماً إلى `main`).
- **مجلد العمل على جهازي:** `C:\xampp\htdocs\almosafir-new` (أي مجلد آخر مثل `almosafir` أو `almosafir_old` قديم ولا يُستخدم).

## 2) التقنيات والبنية (مؤكدة من ملفات المشروع)

- **المنصة الحالية C# / ASP.NET Core (.NET) — وليست PHP.** أي ملفات PHP قديمة في المستودع هي بقايا ميتة من عصر XAMPP ولا علاقة لها بالمنصة الحية.
- **إطار العمل:** ASP.NET Core MVC، الهدف `net10.0` (دوت نت 10)، C# مع `Nullable enable` و `ImplicitUsings enable`.
- **قاعدة البيانات:** MySQL عبر `Pomelo.EntityFrameworkCore.MySql 9.0.0` (EF Core 9). اسم القاعدة `mosafir_db`، الاتصال المحلي `Server=localhost;Port=3306;User=root;Password=;` (بدون كلمة مرور محلياً). الهجرات تُطبَّق تلقائياً عند التشغيل.
- **مزود بديل للمعاينة:** `DbProvider=sqlite` متغير بيئة اختياري (بوابة النشر الحر) — لا يُستخدم في الإنتاج.
- **الوقت الحقيقي:** SignalR (مركزان: `AppHub` للتنبيهات، و`LiveHub` على المسار `/hubs/live` للوحات والمقاعد).
- **الحزم الرئيسية:** Serilog.AspNetCore 9.0.0 (تسجيل)، MailKit 4.16.0 (بريد)، QRCoder 1.6.0 (تذكرة QR)، SQLitePCLRaw.lib.e_sqlite3 3.50.3 (ترقيع CVE-2025-6965).
- **البنية (Clean Architecture):** 4 مشاريع + اختبارات: `AlMosafer.Domain` (الكيانات) → `AlMosafer.Application` (DTOs والواجهات) → `AlMosafer.Infrastructure` (الخدمات و EF Core و MySQL) → `AlMosafer.Web` (MVC والواجهات وwwwroot). ملف الحل: `AlMosafer.slnx`. الاختبارات في `tests/AlMosafer.Tests`.
- **16 متحكماً (Controllers):** Account, Admin, Assistant, Board, Bookings, Conversations, Driver, Home, Lines, Notifications, Payments, Ratings, Tickets, Traveler, Trips, Watchlist.
- **PWA:** manifest + service worker، خط عربي محلي (Cairo)، ومكتبات مباعة محلياً في `wwwroot/lib` (Leaflet 1.9.4، chart.js 4.5.1، lucide، flatpickr) — بدون أي CDN خارجي.

## 3) ما تم إنجازه (كل الميزات)

### أ. المنصة الأساسية (مكتملة ومستقرة)
- تسجيل دخول وتسجيل بصلاحيات (مسافر / سائق / مدير) مع تشفير كلمات المرور PBKDF2 + SHA-256 + Salt.
- **الحجز من البداية للنهاية:** بحث عن رحلة → اختيار مقعد → دفع → تذكرة QR → إمكانية الإلغاء.
- **طرق الدفع:** «نقداً عند الركوب» و«دفع تجريبي فوري» (محاكاة بلا خصم حقيقي). المحافظ الرقمية الحقيقية قادمة لاحقاً (البنية جاهزة).
- لوحة تحكم المدير (Admin): إدارة الرحلات والخطوط والسائقين والإحصاءات.
- المحادثات بين المسافر والسائق، التنبيهات، قائمة المراقبة (Watchlist)، التقييمات.
- شبكة الخطوط الداخلية (جدول `route_lines`).

### ب. لمسات الإنهاء (P50 → P54) — كلها مدموجة في main وتعمل
- **P50 «عصر التطوير»:** المقاعد الحية في صفحة الرحلة (تتحدث لحظياً عبر SignalR) + لوحة الانطلاق في المحطة.
- **P51 «رحلتي الحية»:** صفحة `Traveler/Journey` — خط زمني سردي لرحلة المسافر (محجوز ← تأكيد ← صعود ← وصول) مع نافذة تقييم.
- **P52 «الخريطة»:** خريطة تفاعلية (Leaflet) داخل صفحة تفاصيل الرحلة.
- **P53 «الترحيب»:** شاشة ترحيب (Splash) بشعار المنصة عند فتح أي صفحة، مرة واحدة لكل تبويب (sessionStorage)، تدعم `prefers-reduced-motion`.
- **P54 «مساعد المسافر الذكي» (آخر إنجاز):** مساعد محادثة مدمج بزر عائم أخضر أسفل الشاشة. يجيب بالعربية فوراً وبلا مفاتيح خارجية، يقرأ البيانات الحية من قاعدة البيانات (مثل «كم رحلة متاحة الآن؟»)، يقترح أسئلة جاهزة، ينطق الردود صوتياً (TTS)، ويستقبل إدخالاً صوتياً (STT) حيث يسمح المتصفح. الواجهة: `IAssistantService` (محرك نوايا قاعدي قابل للاستبدال لاحقاً بـ LLM حقيقي مثل OpenAI/Gemini دون لمس باقي الكود).

## 5) أوامر التشغيل (انسخ-الصق حرفياً)

**تحديث المشروع (الأهم — يُحل مشكلة قفل pack):**
```
cd C:\xampp\htdocs\almosafir-new
git -c gc.auto=0 pull --ff-only origin main
```

**تشغيل على اللابتوب فقط:**
```
RUN-ALMOSAFER.bat
```
ثم افتح `http://localhost:5163`

**تشغيل على اللابتوب + الجوال معاً (نفس الشبكة):**
```
RUN-LAN.bat
```
ثم افتح في الجوال العنوان الذي يظهر بجانب السهم (عادة `http://192.168.100.101:5163`).

> الملفان يقتلان تلقائياً أي عملية قديمة على المنفذ 5163 قبل البدء، ويسحبان آخر التحديثات.

## 7) الأمان المطبَّق

- تشفير كلمات المرور PBKDF2 (SHA-256 + Salt فريد) — لا تُخزَّن أي كلمة مرور نصية.
- حماية CSRF في كل النماذج، ترميز تلقائي ضد XSS، منع IDOR (لا يرى المستخدم بيانات غيره)، منع الحجز المزدوج للمقعد.
- رقم هاتف السائق يظهر فقط لمن له علاقة فعلية بالحجز.
- «مساعد المسافر» بلا تغيير حالة (GET آمن من CSRF) ونص يُعرض بـ textContent فقط.

## 8) مشاكل معروفة وحلولها (لا تعيد اكتشافها)

- **المنفذ 5163 مشغول** (`address already in use`): عملية شبحية. الحل: نافذة cmd **مرتفعة الصلاحيات** ثم:
  ```
  for /f "tokens=5" %p in ('netstat -ano ^| findstr :5163 ^| findstr LISTENING') do taskkill /F /PID %p
  ```
  (لا تستخدم PID مثالياً مثل 12345؛ استخدم PID الحقيقي من `netstat -ano | findstr :5163`). ملفا RUN أصبحا يفعلان هذا تلقائياً.
- **قفل pack أثناء git pull** (`Unlink of file pack-...idx failed`): أجب `n`، ثم نفّذ `git -c gc.auto=0 pull --ff-only origin main` (أو `fetch` ثم `reset --hard origin/main` — لكن **fetch أولاً** وإلا بقيت على نسخة قديمة).
- **اللصق الخاطئ في cmd:** لا تلصق سطر الموجه `C:\xampp\htdocs\almosafir-new>` مع الأمر — الصق **الأمر فقط**.
- **تنبيهات البناء الأربعة** (`CS8604` في EmailService.cs): قديمة وغير ضارة، ليست أخطاء.
- **`Failed to determine the https port for redirect` (WRN):** طبيعي لأننا نشغّل http فقط — تجاهله.
- **ملف CI:** `.github/workflows/ci-cd.yml` حُذف من main أثناء دمج P48؛ بيئة التطوير الحالية لا تملك صلاحية إعادة كتابته. البناء على جهازي هو المصدر الأوثق للحقيقة.

## 9) قرارات وقيود ثابتة (التزم بها)

- لا تضع أي بيانات اعتماد إدارية كنص صريح في الكود أو Git.
- لا تفرض الدفع (force-push) ولا تنشئ فروعاً أخرى غير فرع العمل.
- **أوقف اقتراح الاستضافة السحابية** (Render غير متاح/مكلف في اليمن) — `render.yaml` و`DEPLOY_ONE_CLICK.md` خاملان.

- أعطني دائماً أوامر نسخ-لصق حرفية لأي خطوة على جهازي (Windows).
