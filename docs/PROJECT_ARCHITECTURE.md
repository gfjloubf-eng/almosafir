# المرجع المعماري النهائي الشامل — مشروع المسافر AlMosafer
## Project Architecture & Engineering Design Reference

---

## 📌 1. نظرة عامة على المشروع (Project Overview)
نظام **المسافر (AlMosafer)** هو منصة برمجية يمنية متكاملة مخصصة لإدارة وحجز رحلات السفر البرية بين المدن، تربط بين المسافرين والسائقين ومشرفي النظام. يتيح النظام استعراض الرحلات المتاحة، حجز المقاعد، إصدار إيصالات الحجز الرقمية، حصر المدفوعات المسجلة، إجراء المحادثات الفورية وإرسال التنبيهات، تقييم السائقين، وعرض لوحات تحكم وتقارير تحليلية شاملة لدعم اتخاذ القرار.

---

## 🎯 2. المشكلة الفنية والحل الهندسي (Business Problem & Proposed Solution)
- **المشكلة:** عشوائية حجز الرحلات البرية بين المدن، صعوبة التواصل بين المسافر والسائق، غياب الشفافية في الأسعار، وعدم وجود سجلات موثوقة للمدادات المالية والتقييمات والتقارير البيانية.
- **الحل:** بناء منصة Web ذات معمارية برمجية صلبة (**Clean Architecture**) قائمة على **ASP.NET Core 10** وقواعد بيانات **MySQL / MariaDB via XAMPP** تضمن السرعة، السرية، التوافقية، ومنع التقييمات والحجوزات المزدوجة.

---

## 👥 3. الفاعلون في المنظومة (System Actors & Roles)
1. **الزائر (Visitor)**: يستعرض الصفحة الرئيسية، ويبحث عن الرحلات المتاحة، ويمكنه تسجيل حساب جديد (مسافر أو سائق).
2. **المسافر (Traveler)**: يستعرض الرحلات، يحجز المقاعد، يستخرج إيصالات الحجز، يدرج التقييمات، ويتراسل مع السائق.
3. **السائق (Driver)**: ينشر رحلات جديدة، يحدد سعة المقاعد والسعر، يتابع حجوزات ركابه، ويتواصل مع المسافرين.
4. **مدير النظام (Admin)**: يراقب المستخدمين، والرحلات، والحجوزات، والمدفوعات، والتقييمات، والتنبيهات، والمحادثات، ويتابع التقارير البيانية وسلامة المنظومة البرمجية.

---

## 🏛️ 4 & 5 & 6. طبقات المعمارية النظيفة وتدفق الاعتمادات (Clean Architecture & Dependency Flow)

```text
               [ AlMosafer.Web ]  (MVC Controllers, Razor Views, Bootstrap RTL, Chart.js)
                      │
                      ▼
            [ AlMosafer.Application ]  (Interfaces, DTOs, Business Rules)
                      │
                      ▼
              [ AlMosafer.Domain ]  (Entities, Enums, Value Objects)
                      ▲
                      │
          [ AlMosafer.Infrastructure ]  (EF Core DbContext, MySQL Persistence, Hashing, Services)
```

- **`AlMosafer.Domain`**: النواة البرمجية النظيفة (Pure C# Domain). تضم كيانات النظام (`User`, `Trip`, `Booking`, `Payment`, `Rating`, `Notification`, `Conversation`, `Message`) والحالات والأنواع (`UserRole`, `TripStatus`, `BookingStatus`, `PaymentStatus`). لا تعتمد على أي مكتبات خارجية أو إطارات عمل.
- **`AlMosafer.Application`**: طبقة حالات الاستخدام والعقود البرمجية (`Interfaces`) وكائنات نقل البيانات (`DTOs`). تمنع تعريض كيانات قاعدة البيانات المباشرة للواجهات.
- **`AlMosafer.Infrastructure`**: طبقة البنية التحتية المنفذة لاستعلامات EF Core ضد قواعد بيانات MySQL وتشفير الحسابات وخوادم الاتصال.
- **`AlMosafer.Web`**: طبقة العرض والتحكم (ASP.NET Core MVC) وتوفر واجهات Razor TPL وسيناريوهات الأمان والترميز ضد Thrid-Party Attacks.

## 🗄️ 7 & 8. قواعد البيانات (Database Schema Overview)
قاعدة البيانات **`mosafir_db`** تعمل على خادم **MySQL / MariaDB via XAMPP** على المنفذ `3306`:
1. `users`: جدول الحسابات والتأمين والأدوار والتفاصيل.
2. `trips`: جدول الرحلات وخطوط السير والأسعار وسعة المقاعد.
3. `bookings`: جدول الحجوزات وعدد المقاعد وتاريخ الحجز.
4. `payments`: جدول المدفوعات والمعاملات المالية المسجلة.
5. `ratings`: جدول التقييمات والمراجعات المربوطة بالرحلات.
6. `notifications`: جدول سجل الإشعارات البرمجية.
7. `conversations`: جدول جلسات المحادثة.
8. `messages`: جدول الرسائل النصية المتبادلة.

## 🔐 9 & 10. التوثيق والصلاحيات والحماية (Auth, Authorization & Security Controls)
- **التوثيق وتشفير كلمة المرور**: استخدام خوارزمية **PBKDF2 مع SHA-256** والملح العشوائي (**Salt**) لمنع Rainbow Tables.
- **إدارة الصلاحيات (Role Authorization)**:
  - `Admin`: حماية حصريّة عبر `[Authorize(Roles = "Admin")]`.
  - `Driver`: `[Authorize(Roles = "Driver,Admin")]`.
  - `Traveler`: `[Authorize(Roles = "Traveler,Admin")]`.
- **حماية ثغرة IDOR**: التحقق من ملكية الحساب والموارد سطرًا بسطر بالسيرفر باستخدام `User.FindFirstValue(ClaimTypes.NameIdentifier)`.
- **حماية CSRF & XSS**: تطبيق `[ValidateAntiForgeryToken]` والترميز التلقائي التام في محرك Razor Views.

## 🔄 11 - 17. تدفقات العمليات البرمجية (Core Workflows)
1. **تدفق الحجز (Booking Workflow)**: فحص توفر المقاعد وتأكيد الحجز وتوليد الإشعار وإصدار الإيصال وسجل الدفع.
2. **تدفق التقييم (Rating Workflow)**: منع التقييم المكرر، منع تقييم السائق لنفسه، والتحقق من اكتمال الرحلة قبل التقييم.
3. **تدفق التقارير (Reporting Workflow)**: استعلامات تجميعية حقيقية 100% من قاعدة البيانات دون أي بيانات وهمية.
