# التوزيع والبثّ: كيف تصبح المنصة «تطبيقاً» على الدسكتوب والويب معاً؟

**التاريخ:** 2026-08-31 · يجيب على سؤال المالك: «أريده تطبيقاً يُثبَّت… كيف تُبثّ المعلومات وما الطرق… وكيف يكون دسكتوب وويب في نفس الوقت؟»

---

## 1) الخوارزمية الهندسية: كود واحد يخدم الدسكتوب والويب والجوال

نحن أصلاً **تطبيق ويب واحد** (ASP.NET Core). ليصبح «يُثبَّت كتطبيق» لا نبني نسخة ثانية — بل نفعّل معيار **PWA**:

```
┌────────────ـ خادم ASP.NET Core واحد (ارجل HTML) ────────────┐
│                                                             │
 ▼ المتصفح يقرأ:                                               ▼
<meta manifest>  +  sw.js (عامل خدمة)  +  أيقونات + theme
        │
        ├─ «إضافة إلى الشاشة الرئيسية» على الجوال → أيقونة + شاشة كاملة
        ├─ «Install app» على Chrome/Edge دسكتوب → نافذة مستقلة خاصة
        └─ يبقى يعمل كموقع عادي في كل متصفح آخر — نفس الكود ونفس القاعدة!
```

هكذا «دسكتوب وويب في نفس الوقت» حرفياً: **نفس الرابط، ونفس الحساب، ونفس البيانات** — التثبيت مجرد غلاف متصفح مستقل. لا حاجة لنسخة EXE ولا متجر تطبيقات لهذه المرحلة.

## 2) ما فُعّل اليوم (P39)
- `manifest.webmanifest` (عربي RTL، أيقوناتنا المرسومة/المولّدة، لون الثيم الداكن #0f172a).
- `sw.js`: يخبّئ **الأصول الثابتة فقط** ويقدّم صفحة «انقطع الاتصال 📡» المهذبة عند انقطاع الشبكة — وسياسة محافظة مقصودة: صفحات الحساب **شبكة-أولاً دائماً** حتى لا يُعرض محتوى خاص متقادم.
- `offline.html` + تسجيل تلقائي في `_Layout` + خانة «ثبّت كتطبيق» في الإعدادات.

## 3) كيف تُبثّ المعلومات في منصتنا؟ (مصفوفة القنوات الحالية)

| القناة | الطبقة | متى تعمل | مثال حي |
|---|---|---|---|
| إشعار داخلي | `NotificationService` + جرس القائمة | فوري داخل المنصة | «انطلقت رحلتك 🚌» |
| بريد إلكتروني | `EmailService`/MailKit | عند توفر SMTP | استعادة كلمة المرور |
| دردشة نصية | `MessageService` + تحديث كل 15ث | أثناء المحادثة | تنسيق الأمتعة |
| تذكرة QR | QRCoder على الإيصال | عند العرض/الطباعة | إثبات الحجز عند الركوب |
| مشاركة خارجية | روابط واتساب | بيد المستخدم | دعوة صديق للخط |
| **لحظية حية** | SignalR | **مؤجلة** — ملف عميلها محجوب من بيئة بناء المساعد اليوم (jsDelivr/UNPKG) | تحويل الدردشة لحظية |

## 4) ما لا يدّعيه هذا الحل (صدق)
- PWA لا يعني متجر Google Play — التثبيت من المتصفح مباشرة.
- عامل الخدمة يتطلب HTTPS أو localhost (XHR: محلي عبر XAMPP ✓ / Render للإنتاج ✓).
- التتبع الحي بالخرائط يتطلب قرار استضافة عامة + ملفات Leaflet المُوفَّدة (خارطة P40).
