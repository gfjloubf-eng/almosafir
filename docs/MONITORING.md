# دليل المراقبة وفحص صحة التطبيق والقواعد — مشروع المسافر AlMosafer
## Enterprise Health Monitoring & Diagnostics Guide

---

## 📌 1. نقطة فحص الصحة والسلامة السحابية (`/health`)
تم تسجيل خدمة وميدلوير `/health` رسميًا في `Program.cs` لتوفير استجابة آمنة ومختصرة حول سلامة التطبيق:
- **الرابط المحلي:** `http://localhost:5163/health`
- **الرابط السحابي:** `https://almosafir-app.onrender.com/health`
- **حالات الاستجابة:**
  - `200 OK` + `Healthy`: التطبيق وقاعدة البيانات يعملان بسلاسة.
  - `530 / 500` + `Unhealthy`: وجود مشكلة تشغيلية دون تعريض التفاصيل الداخلية.

---

## 📊 2. المراقبة التشغيلية عبر لوحة الإدارة (`System Health`)
تتيح شاشة **صحة النظام (System Health)** داخل لوحة الإدارة `/Admin/SystemHealth` قياس المؤشرات الفنية المباشرة:
- حالة الاتصال بقاعدة البيانات MySQL.
- إحصائيات المعاملات اليومية والحجوزات الناجحة.
- فحص حجم الجداول وحالة استعلامات الأداء.
