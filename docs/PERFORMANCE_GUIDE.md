# دليل تحسين الأداء والاستعلامات — مشروع المسافر AlMosafer
## Enterprise Performance Engineering & Query Optimization Guide

---

## ⚡ 1. تحسين استعلامات قواعد البيانات (EF Core Query Optimization)
- **القراءة بدون تتبع (`.AsNoTracking()`):** تطبيق هذا الخيار على كافة استعلامات القراءة فقط في جميع الخدمات الإدارية والتقارير ولوحات التحكم لمنع استهلاك الذاكرة وإجهاد المحرك.
- **منع مشكلة N+1 Query:** استخدام `Include` و `ThenInclude` بحذر ودقة عالية وضمان جلب البيانات المطلوبة في استعلام موحد.
- **التجميع على الخادم (Server-Side Aggregations):** تنفيذ التجميعات الحسابية والإحصائية (`CountAsync`, `SumAsync`, `AverageAsync`, `GroupBy`) كلياً داخل خادم MySQL وتجنب جلب الجداول كاملة للذاكرة.

---

## 🗄️ 2. الفهارس ودقة البيانات (Indexing & Data Precision)
- **الفهارس المفتاحية:** اعتماد الفهارس التلقائية للمفاتيح الرئيسية والأجنبية (`Primary Keys`, `Foreign Keys`).
- **الدقة المالية:** ضبط نوع البيانات المالية في EF Core Fluent API ليكون `decimal(18,2)` لمنع أي انحرافات رقمية أو أخطاء الأعداد العائمة.

---

## 🚀 3. سرعة استجابة الواجهة (UI Rendering Performance)
- ضغط وحزم ملفات CSS و JavaScript وتصغير حجم الاستجابات الحجمية.
- استخدام التخزين المحلي المؤقت (Local Caching) في المتصفح للأصول الثابتة والصور وأيقونات Bootstrap.
