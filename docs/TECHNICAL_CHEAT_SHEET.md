# كراسة المفاهيم والمصطلحات التقنية لمناقشة التخرج — مشروع المسافر AlMosafer
## Technical Cheat Sheet for Academic Viva Defense

---

### 1. C# & .NET 10
- **C#**: لغة برمجية كائنية التوجه (OOP) قوية ومتطورة تطورها Microsoft.
- **.NET 10**: إطار العمل الأحدث والأسرع لتطوير تطبيقات السيرفر متعددة المنصات (Cross-Platform).

### 2. ASP.NET Core MVC & Razor
- **MVC Pattern**: معمارية تفصل بين الموديل (Model)، العرض (View)، والمتحكم (Controller).
- **Razor**: محرك قوالب يدمج كود C# داخل صفحات HTML بسلاسة مع ترميز آمن تلقائي ضد XSS.

### 3. Clean Architecture
- **المعمارية النظيفة**: نمط يعزل قواعد العمل المركزية (Domain) عن إطارات العمل والتفاصيل التقنية (Infrastructure/Web)، مما يجعل النظام قابلاً للاختبار والصيانة.

### 4. Dependency Injection (DI)
- **حقن الاعتمادات**: تقنية لتوفير الخدمات والاعتمادات للعمليات تلقائياً دون الحاجة لإنشائها يدويًا داخل المتحكمات (`new Service()`).

### 5. Entity Framework Core (EF Core) & LINQ
- **EF Core**: إطار تعيين الكائنات بالبيانات (ORM) يربط كود C# بـ MySQL دون كتابة SQL يدويًا.
- **`.AsNoTracking()`**: ميزة في EF Core تلغي تتبع التغييرات في استعلامات القراءة فقط لتوفير الذاكرة وسرعة الاستجابة.
- **LINQ**: لغة الاستعلام المدمجة في C# لاستعلام الكائنات وقواعد البيانات.

### 6. XAMPP & MySQL / MariaDB
- **XAMPP**: بيئة تطوير محلية تتيح تشغيل خادم MySQL / MariaDB على المنفذ `3306`.
- **`mosafir_db`**: قاعدة البيانات العلاقية المركزية للنظام.

### 7. Security Controls (PBKDF2, IDOR, XSS, CSRF)
- **PBKDF2 / SHA-256**: خوارزمية تشفير وتمليح (Salt) كلمات المرور لحمايتها من هجمات Rainbow Tables.
- **IDOR Guard**: التحقق من ملكية الحجز أو المورد على السيرفر برقم ID المالك الحقيقي في التذكرة.
- **CSRF Guard**: حماية النماذج ضد التزوير عبر `[ValidateAntiForgeryToken]`.
- **XSS Guard**: منع التسلل النصي عبر الترميز التلقائي التام في Razor Views.

### 8. Financial & Concurrency Integrity
- **`decimal(18,2)`**: نوع البيانات الدقيق للحسابات المالية لمنع أخطاء الأعداد العائمة (Floating Point Errors).
- **منع تجاوز المقاعد (Overbooking Prevention)**: قفل المعاملات وفحص المقاعد المتاحة لحماية المقعد الأخير من الحجز المزدوج.

### 9. Chart.js & Testing
- **Chart.js**: مكتبة رسومات بيانية تفاعلية تستهلك بيانات JSON حقيقية من السيرفر.
- **Unit Testing (xUnit)**: حزمة اختبارات آلية تتأكد من صحة وسلامة منطق الكود وحمايته.
