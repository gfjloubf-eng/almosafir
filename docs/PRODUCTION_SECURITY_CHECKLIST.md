# قائمة فحص الجاهزية والأمان للإنتاج — مشروع المسافر AlMosafer
## Enterprise Production Security Checklist

---

- [x] **تشفير كلمات المرور:** استخدام خوارزمية PBKDF2 مع SHA-256 والملح العشوائي Salt.
- [x] **حماية IDOR:** التحقق من ملكية الحجز والمدفوعات والمحادثات على خادم السيرفر عبر `ClaimsPrincipal`.
- [x] **حماية CSRF:** تطبيق `[ValidateAntiForgeryToken]` على كافة عمليات الإرسال POST.
- [x] **حماية XSS:** الترميز النصي التلقائي التام في محرك Razor الخالي من `Html.Raw` غير الآمن.
- [x] **تقييد معدل الطلبات (Rate Limiting):** تطبيق سياسة `StrictLimiter` على عمليات التوثيق والحجز.
- [x] **حماية أسرار الكود:** خلو مستودع Git والملفات العامة من أي أسرار أو كلمات مرور.
- [x] **إدارة الأخطاء:** إخفاء أخطاء الـ Stack Traces عن المستخدم النهائي وإظهار صفحات خطأ آمنة.
- [x] **فحص الأنشطة والعمليات:** تسجيل الأحداث والأخطاء تشخيصياً عبر ASP.NET Core Structured Logging.
- [x] **دعم الخوادم الوكيلة (Forwarded Headers):** التوافق التام مع Cloud Reverse Proxies على السحاب.
