# دليل المراقبة والتسجيل البرمجي — مشروع المسافر AlMosafer
## Enterprise Observability & Structured Logging Guide

---

## 📌 1. سياسة التسجيل البرمجي (Logging Philosophy)
يعتمد نظام المسافر على معيار **ASP.NET Core Built-in Structured Logging** لتوفير تسجيل تشخيصي متكامل للأحداث التشغيلية دون تعريض أي بيانات حساسة أو تدمير للأداء.

---

## 🎯 2. الأحداث المسجلة (Logged Events)
1. **الأحداث الأمنية (Security Events):**
   - محاولات تسجيل الدخول الفاشلة الناجمة عن كلمة مرور خاطئة.
   - حالات رفض الوصول لصفحات الإدارة (`Access Denied`).
2. **الأحداث التشغيلية (Business Operations):**
   - إنشاء رحلة جديدة من قبل السائق.
   - طلبات حجز المقاعد وحالات تأكيد الحجز أو تعارض المقاعد.
   - تسديد وتسجيل عمليات الدفع الداخلية.
   - إنشاء التقييمات والمراجعات جديدة.
3. **الأحداث الفنية والاستثناءات (Technical Exceptions):**
   - حالات انقطاع الاتصال بقواعد بيانات MySQL.
   - الأخطاء غير المتوقعة (Unhandled Exceptions) وتحويلها لصفحة خطأ آمنة.

---

## 🛑 3. البيانات المحظور تسجيلها (Security Non-Negotiables)
يُحظر حظرًا تامًا تسجيل أيٍّ مما يلي في سجلات النظام:
- كلمات المرور قبل أو بعد التشفير (`Passwords`, `PasswordHashes`).
- رموز التوثيق وجلسات الكوكيز (`AuthTokens`, `Cookies`).
- محتوى الرسائل الخاصة بين المستخدمين.
- نصوص استعلامات قواعد البيانات الحاملة لبيانات مالية حساسة.

---

## 🔍 4. ربط وتتبع الطلبات (Correlation Identifiers)
يتم تعيين `TraceIdentifier` فريد لكل طلب HTTP وارد عبر ASP.NET Core Middleware لمتابعة تتبع الاستجابة عبر الطبقات المختلفة وحل المشكلات الفنية بسرعة وسهولة.
