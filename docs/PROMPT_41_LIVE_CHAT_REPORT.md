# تقرير «النبض الحي — الموجة ٢»: الدردشة اللحظية + ختم حقوق الطبع © 2026–2027

**التاريخ:** 2026-08-31 · **الطلب:** تنفيذ الخارطة خلال الشهر الجاري + «2026–2027 حقوق الطبع محفوظة لدى عمار الموعي».

## 1) ختم الحقوق

- تذييل الموقع (كل الصفحات عبر `_Layout.cshtml`): **«© 2026–2027 منصة المسافر AlMosafer Platform — حقوق الطبع محفوظة لدى عمار الموعي»**.
- نفس الختم أُثبت في ترويسة خارطة الطريق.
- حقول «فريق الدعم» في الإعدادات بقيت بالاسم الكامل الرسمي: عمار عادل المصوعي — بمساعدة عبد الملك فواز.

## 2) الدردشة اللحظية (البند 2 من الخارطة — مُنجَز)

قبل: صفحة المحادثة تسأل الخادم كل 15 ثانية (polling). الآن:

```
رسالة تُحفظ في القاعدة (مصدر الحقيقة — MessageService الأصلي بلا لمس)
        │
        ▼  مزخرف RealtimeMessageServiceDecorator (فشل البث لا يُسقط الرسالة)
   ┌────┴─────────────────┐
   ▼                      ▼
 مجموعة conv-{id}      مجموعة user-{المستلم}
 من يقرأ المحادثة     خارج المحادثة؟ تنبيه عائم
 يراها فوراً          «رسالة جديدة من …»
```

| القطعة | الملف | ملاحظة |
|---|---|---|
| مزخرف الرسائل | `Web/Services/RealtimeMessageServiceDecorator.cs` | يلتفّ `MessageService`؛ يستعلم الطرفين بقراءة AsNoTracking. |
| انضمام آمن | `Hubs/AppHub.cs` → `JoinConversation(int id)` | **فحص عضوية قاعدة البيانات أولاً** — غير الطرفين يُرفض صامتاً (IDOR). |
| عميل | `wwwroot/js/realtime.js` | حدث `ReceiveMessage`؛ إن كنت مطابقاً للمحادثة المفتوحة → تحديث فوري (CustomEvent)، وإلا تنبيه عائم؛ يتجاهل رسائلك أنت. بعد إعادة الاتصال: تحديث العدّاد + إعادة الانضمام تلقائياً. |
| صفحة المحادثة | `Views/Conversations/Details.cshtml` | استُخرج جسم الجلب في دالة واحدة `refresh`؛ نبضة SignalR تستدعيها فوراً، وتبقى دورة الـ15ث كشبكة أمان. `data-conversation-id` للمطابقة. |
| Wiring | `Program.cs` + `_Layout.cshtml` (بثّ `window.__uid` للمتحقَّقين فقط) | نفس نمط الديكوريتر المعتمد في الموجة ١ — صفر تعديل بالاختبارات. |

## 3) جدولة الخارطة (قرار المالك)

- غير محجوب خارجياً → يُنفَّذ هذا الشهر: ✅ اللحظية (موجتان)، ثم: بريد استعادة كلمة مرور (SMTP بحت)، تذكرة موقعة، تسويات السائقين، عمل بلا نت جزئي، سجلات مهيكلة.
- محجوب حتى وفادة مفاتيح المالك: OTP برسائل SMS، المحفظة الحقيقية.
- أي بند بحاجة عمود/جدول جديد يُعلَن قبله صراحةً ويُشترط `dotnet ef database update` لديك.

## حدود صادقة

- التنبيه العائم يعمل والتبويب مفتوح؛ Push حقيقي والتطبيق مغلق يحتاج VAPID+HTTPS عام (خارج النطاق المحلي).
- دالة الجلب بالاستبدال الكامل للقائمة حذرة: لن تمس رسالةً تكتبها الآن (تتخطى الدورة إذا كان حقل الكتابة غير فارغ).

## التحقق اليدوي

افتح المحادثة في تبويبين (سائق/مسافر) → أرسل من الأول → الثاني يرى الرسالة **فوراً** دون انتظار 15ث، وباقي الصفحات تتلقى تنبيهاً عائماً.
