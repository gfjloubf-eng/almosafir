# دليل دورة الفحص الميداني والاختبار المباشر — مشروع المسافر AlMosafer
## Enterprise Production Smoke Test & Journey Verification Guide

---

## 📌 1. خطوات الفحص الشامل الميداني (22 Core Journeys)

1. **الصفحة الرئيسية:** فتح `http://localhost:5163` وتصفح الرحلات المعروضة.
2. **تسجيل مسافر جديد:** إنشاء حساب مسافر واختبار التحقق من البريد والهاتف.
3. **تسجيل الدخول:** تسجيل الدخول بحساب المسافر وتحديث الجلسة.
4. **لوحة المسافر:** تصفح الحجوزات النشطة والتنبيهات.
5. **البحث عن رحلة:** البحث عن رحلة بين مدينتين (`صنعاء ← عدن`).
6. **تفاصيل الرحلة:** معاينة المقاعد والسعر وملاحظات السائق.
7. **تأكيد الحجز:** حجز مقعد وإصدار إيصال الحجز الرقمي.
8. **سجل الدفع الداخلي:** التأكد من قيد العملية المالية المسجلة بنجاح.
9. **الإشعارات والتنبيهات:** استلام تنبيه تأكيد الحجز.
10. **المحادثات الخاصة:** مراسلة السائق وتصفح الرسائل المتبادلة.
11. **التقييمات والمراجعات:** إضافة تقييم وسرد مراجعة بعد اكتمال الرحلة.
12. **إدارة الملف الشخصي:** تحديث الاسم ورقم الهاتف والتأكد من الحفظ.
13. **تغيير كلمة المرور:** فحص تحديث كلمة المرور والتأكد من التشفير.
14. **إعدادات الحساب:** معاينة إعدادات الخصوصية والحساب.
15. **تسجيل دخول السائق:** الدخول بحساب السائق وتصفح الواجهة.
16. **لوحة السائق:** معاينة الأرباح المقدرة والركاب.
17. **نشر رحلة جديدة:** تعبئة تفاصيل رحلة برية ونشرها بنجاح.
18. **تسجيل دخول الإدارة:** الدخول بحساب مدير النظام `admin@almosafir.com`.
19. **لوحة الإدارة الشاملة:** تصفح مستخدمي النظام والرحلات والحجوزات والمدفوعات.
20. **التقارير التحليلية:** معاينة الرسوم البيانية والجداول الإحصائية.
21. **صحة النظام:** فحص الاتصال بقواعد البيانات واستجابة السيرفر.
22. **تسجيل الخروج:** خروج أمن من الجلسة وتحديث الكوكيز.
