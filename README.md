# Almosafir 🚗

World-class ridesharing platform like BlaBlaCar for Yemen/Arabic regions.

## Quick Start (XAMPP)
1. Import `db_setup.sql` to phpMyAdmin (mosafir_db).
2. Start Apache/MySQL.
3. Visit `http://localhost/almosafir`.

## Features
- Post/search/book trips
- User auth (register/login)
- Mock payments
- Admin dashboard
- Arabic RTL support

## Tech
- PHP 8+, MySQL, HTML/CSS/JS
- Local dev only
