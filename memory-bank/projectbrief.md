# Project Brief: Almosafir

- **Goal**: Build a world-class ridesharing/travel platform like BlaBlaCar for Yemen/Arabic regions. Features: trip posting, booking, payments, chat, ratings, admin dashboard. Multi-platform (PHP web, React, Flutter).
- **Non-goals**: Real payment gateway (mock), production deploy (dev only).
- **Success criteria**: Full user flow works locally on XAMPP, GitHub Pages live demo, clean code/tests, Claude MCP integrated as dev team.
